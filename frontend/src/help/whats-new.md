# What's new

## VIKI Agent 0.2.0

Bots that learn only what you approve, a Vault and Kanban that are easier to read, and more chats at once.

- **Bots learn only what you approve.** On a Bot's page, **Reflect now** and **Dream now** propose what the Bot should remember, with the evidence quoted. Nothing is kept until you **Apply** it. **Import earlier memory** offers a Bot's older memory files the same way.
- **Vault reader.** On **Knowledge**, **Sources**, **Maps** and **Everything else**, an opened note sits beside the list in a wide window. With no note open, **Knowledge**, **Sources** and **Maps** show the section at a glance.
- **Kanban answers.** **Needs you** lists the cards waiting for you, with one-click answers and 10 seconds to undo. In a vault VIKI Agent doesn't save to, your answer goes to the card's Bot as a message you see before it is sent.
- **Bot threads.** A working Bot shows one status line, and a finished Bot shows its message; **Open Bot chat** still shows every step.
- **More chats at once.** Up to 30 Claude Code sessions run at the same time, up from 8. Change it in **Settings › Chat › Sessions running at once**.
- **Answer first.** Decision's plans, Kanban cards and Bot messages lead with the answer, and the evidence folds under **Details**.
- **Bot usage.** **Bots → Usage** shows how many tokens your Bots used, by day, Bot, model and conversation, for the last 7, 30 or 90 days.
- **Ask a chat to change settings.** It can also add and test routines and create Bots; turning on a routine and safety-list changes wait for your Apply.
- **Starter updates.** A vault made with **Start with VIKI** can take newer starter files without losing your edits: see **Settings › Instructions and Persona**.
- **Inbox suggestions** are kept when VIKI Agent restarts.

## VIKI Agent 0.1.0

The first public release of VIKI Agent.

- **Your own Claude Code.** Every chat runs Claude Code with the instructions, skills, hooks and permissions it applies in that folder, and asks for your permission with **Allow once** and **Deny**.
- **Bring your own model.** Chats use the sign-in your Claude Code is set up with, such as your Claude plan, an API key or a cloud provider. To use another model, add a connection in **Settings › Providers**: a model or routing group from Magpie, or a direct connection, including a model server on this computer.
- **Vault.** Browse your notes in the Vault view and quote one into a chat. In an ordinary vault on a supported drive, you can save, rename, move, archive, delete and restore notes.
- **Decision.** Turn on **Proactive VIKI** to let VIKI suggest or start work within **What VIKI may do**. Several grants start as **Allowed**, so review them first.
- **Bots and Kanban.** Chief turns your request into Kanban cards, the specialists work them, and Checker checks finished work against its **Done when** items. Each Bot keeps its own memory and follows VIKI Agent's Bot rules instead of the vault's own instructions.
- **Setup.** **Help → Setup guide** shows what is set up and what is left.
